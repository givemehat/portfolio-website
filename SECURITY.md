# Security policy

## Supported versions

Only the latest version on the default branch is supported.

## Reporting a vulnerability

Please do not disclose security issues in a public issue. Report them privately
through [GitHub's private vulnerability reporting](https://github.com/givemehat/portfolio-website/security/advisories/new).

This site is a static frontend. It does not provide secure server-side
authentication, so administrative editing is disabled in the public build.
