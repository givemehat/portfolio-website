Welcome to the source code of my personal portfolio! This is a static web application built to showcase my projects, skills, research, and publications in Artificial Intelligence (AI), Machine Learning (ML), and Quantum Computing (IBM Qiskit).

## Features
- **Responsive Design**: Mobile-friendly, accessible layout.
- **GSAP Animations**: Smooth scrolling and visual micro-interactions.
- **Sections**: Home, About, Research, Projects, Publications, Certifications, Books, and Experience.
- **Dark/Light Theme**: Built-in theme toggler for better user experience.
- Hosted automatically on GitHub Pages.

## Tech Stack
- HTML5 / CSS3 (Vanilla CSS with tokens and custom properties)
- JavaScript (with GSAP and ScrollTrigger for animations)
- Semantic HTML and Schema.org JSON-LD for SEO

## Local Development
To run this project locally, you can use any static file server, for example:

```bash
# Using Python 3
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
